# 가계부 프로그램 SPEC

## 1. 프로젝트 개요
Python 3.10+와 Flet 1.0을 사용하여 제작하는 단일 창 구성의 가계부 프로그램입니다. 수입과 지출을 기록하고, 저장된 데이터를 통해 총 수입, 총 지출, 잔액을 실시간으로 관리합니다.

## 2. 기술 스택 및 제약 사항
- **Language**: Python 3.10 이상
- **Framework**: Flet 1.0 (제공된 `main.py` 뼈대의 문법만 사용하며, 구버전 문법 사용 금지)
- **Library**: 표준 라이브러리(`json`, `os` 등)만 사용 가능. 그 외 외부 패키지 사용 금지.
- **Flet 1.0 사용 주의사항**:
    - `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `ft.UserControl`, `TextField(error_text=...)` 등 구버전 속성/클래스 사용 엄격 금지.

## 3. 파일 구성 및 역할
- **`main.py`**: 사용자 인터페이스(UI) 담당. `logic.py`의 함수를 호출하여 비즈니스 로직을 처리함.
- **`logic.py`**: 핵심 계산 및 판정 로직 담당. Flet을 import하지 않으며, 순수 파이썬 함수로만 구성.
- **`test_logic.py`**: `logic.py`의 함수들을 검사하는 테스트 파일. 실행 시 통과와 실패 수를 출력.
- **`data.json`**: 가계부 데이터를 영구 저장하기 위한 JSON 파일.

## 4. 기능 요구사항

### 4.1 데이터 입력 및 관리
- **입력 항목**: '내역(String)'과 '금액(Integer)'.
- **구분 선택**: '수입' 또는 '지출' 중 선택.
- **유효성 검사**:
    - 금액은 반드시 0보다 큰 정수여야 함.
    - 0 이하의 금액을 입력할 경우, 추가하지 않고 화면의 안내 문구 영역에 에러 메시지를 표시함.
- **저장**: 입력된 데이터는 즉시 `data.json`에 반영되어야 함.

### 4.2 목록 표시 및 삭제
- **목록 레이아웃**: `[구분] 내역 | 금액 | [삭제 버튼]` 형식으로 한 줄씩 표시.
- **금액 포맷팅**: 모든 금액은 천 단위마다 쉼표(`,`)를 포함하여 표시 (예: `1,000`).
- **삭제 기능**: 목록의 각 항목 옆에 있는 '삭제' 버튼을 누르면 해당 항목이 제거되고, `data.json`이 업데이트되며, 총합 및 잔액이 재계산됨.

### 4.3 요약 정보 표시
- 화면 하단에 다음 정보를 실시간으로 업데이트하여 표시:
    - **총 수입**: 모든 수입 항목의 합계.
    - **총 지출**: 모든 지출 항목의 합계.
    - **현재 잔액**: (총 수입 - 총 지출).

## 5. UI 레이아웃 설계 (Layout)
1. **상단 (Input Area)**:
   - 내역 입력란 (TextField)
   - 금액 입력란 (TextField)
   - 구분 선택 (Dropdown)
   - 추가 버튼 (Button)
   - 에러/안내 메시지 영역 (Text)
2. **중앙 (List Area)**:
   - 거래 내역이 나열되는 스크롤 가능한 영역 (Container with Scrollable Column).
3. **하단 (Summary Area)**:
   - 총 수입, 총 지출, 잔액을 보여주는 텍스트 영역.
