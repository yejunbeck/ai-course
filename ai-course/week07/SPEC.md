# 가계부 프로그램 (Flet 1.0) 설계서 (SPEC)

## 1. 프로젝트 개요
사용자가 수입과 지출을 기록하고, 카테고리별로 관리하며, 실시간으로 통계를 확인할 수 있는 단일 창 가계부 프로그램입니다.

## 2. 기능 요구사항

### 2.1 데이터 관리
- **영구 저장**: `json` 모듈을 사용하여 데이터를 `data.json` 파일에 저장하고 프로그램 시작 시 로드합니다.
- **항목 구성**: 각 내역은 `구분(수입/지출)`, `금액(정수)`, `카테고리(5종)`, `내용(텍스트)`을 포함합니다.

### 2.2 입력 및 유효성 검사
- **금액 검증**: 금액은 반드시 0보다 큰 정수여야 합니다.
- **에러 피드백**: 금액이 0 이하이거나 정수가 아닌 경우, 입력창 근처의 전용 에러 메시지(`ft.Text`)를 통해 안내 문구를 출력합니다.
- **카테고리**: 미리 정의된 5가지 카테고리 중 하나를 선택할 수 있어야 합니다.

### 2.3 내역 목록 및 삭제
- **목록 표시**: `ft.ListView`를 사용하여 입력된 내역을 스크롤 가능한 형태로 보여줍니다.
- **천 단위 쉼표**: 모든 금액 표시에는 천 단위 구분 기호(`,`)를 적용합니다.
- **삭제 기능**: 각 내역 줄에는 '삭제' 버튼이 있으며, 클릭 시 해당 내역이 제거되고 통계가 즉시 갱신됩니다.

### 2.4 통계 및 요약
- **실시간 업데이트**: 내역이 추가되거나 삭제될 때마다 하단의 통계 영역이 자동으로 계산됩니다.
- **표시 항목**: '총 수입', '총 지출', '현재 잔액' 세 가지를 화면 하단에 명확히 표시합니다.

## 3. 기술 사양

### 3.1 환경 및 라이브러리
- **Language**: Python 3.10+
- **Framework**: Flet 1.0
- **Constraints**:
    - 외부 패키지 사용 금지 (Python 표준 라이브러리 `json`, `random` 등만 허용).
    - **Flet 1.0 문법 엄수**: 아래 항목 사용 시 오류 발생하므로 주의할 것.
        - `ft.app()` 사용 불가 (제공된 뼈대 구조 유지).
        - `ft.colors` 사용 불가 (문자열 색상 지정 활용).
        - `ft.alignment.center` 사용 불가.
        - `ft.ElevatedButton` 사용 불가.
        - `ft.UserControl` 사용 불가.
        - `ft.TextField(error_text=...)` 사용 불가.

### 3.2 파일 구성
- `SPEC.md`: 본 설계 문서.
- `logic.py`: 
    - Flet을 import하지 않는 순수 파이썬 모듈.
    - 데이터 입출력(JSON), 계산(합계, 잔액), 유효성 판정 로직 담당.
- `main.py`: 
    - Flet 1.0 기반 UI 레이아웃 구현.
    - 모든 계산 및 데이터 처리는 `logic.py`의 함수를 호출하여 수행.
- `test_logic.py`: 
    - `logic.py`의 함수들이 정확히 동작하는지 검증하는 테스트 코드.
    - 실행 시 통과/실패 횟수를 출력.
