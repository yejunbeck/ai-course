# 주차 요금 계산기 (Parking Fee Calculator) - Specification

## 1. 개요
본 프로그램은 Python의 Flet 프레임워크를 사용하여 제작되는 단일 창(Single Window) 형태의 주차 요금 계산기입니다. 입차 및 출차 시각(날짜 포함)을 입력받아 주차 시간을 계산하고, 규정에 따른 요금을 산출하여 목록으로 관리하며, 당일의 총 합계 금액을 실시간으로 보여주는 기능을 제공합니다.

## 2. 기술 스택
- **Language**: Python 3.10+
- **Framework**: Flet 1.0 (Flutter-based UI framework)
- **Data Persistence**: Memory-based (프로그램 종료 시 데이터 휘발)
- **Constraints**: 
    - 외부 패키지 사용 금지 (표준 라이브러리만 허용: `random`, `json`, `datetime` 등)
    - Flet 1.0 문법 엄격 준수 (구버전 문법 사용 금지)

## 3. 파일 구성
- **`logic.py`**: 핵심 비즈니스 로직 담당.
    - Flet을 import 하지 않음 (Pure Python).
    - 입력을 받아 계산 및 판정을 수행하고 결과를 반환하는 함수들로 구성.
- **`main.py`**: UI 및 사용자 인터랙션 담당.
    - Flet 1.0 기반의 화면 뼈대 구현.
    - 모든 계산 로직은 `logic.py`의 함수를 호출하여 수행.
- **`test_logic.py`**: `logic.py` 단위 테스트 담당.
    - `logic.py`의 함수들을 검증.
    - 실행 시 테스트 통과(Pass) 및 실패(Fail) 수를 출력.

## 4. 기능 요구사항

### 4.1 입력 및 계산 기능
- **입/출차 정보 입력**: 
    - 날짜 선택기(`DatePicker`)를 통해 날짜를 선택함.
    - 시각은 Flet의 `TimePicker`를 사용하여 사용자가 시/분을 쉽게 선택할 수 있도록 함.
- **요금 산정 로직**:
    - **무료 구간**: 주차 시작 후 첫 30분까지는 0원.
    - **유료 구간**: 30분 경과 후부터 10분마다 500원씩 부과.
    - **올림 규칙**: 10분이 채 되지 않는 나머지 시간도 10분으로 간주하여 계산.
    - **최대 요금 제한**: 개별 주차 건당 최대 요금은 **20,000원**으로 제한함.
- **검증 (Validation)**:
    - 출차 시각이 입차 시각보다 빠를 경우 계산을 진행하지 않음.
    - 입력값 오류 시 사용자에게 `SnackBar`를 통해 경고 메시지를 표시함.

### 4.2 목록 및 합계 관리 기능
- **주차 기록 목록**:
    - 계산된 각 항목은 [입차 일시, 출차 일시, 주차 시간, 요금] 정보를 포함하여 목록에 추가됨.
    - **정렬 기준**: 가장 최근에 계산된 항목이 목록의 **최상단(Top)**에 위치함.
    - 목록은 스크롤 가능한 형태(`ListView`)로 구현하여 많은 데이터도 확인할 수 있어야 함.
    - 각 행(Row)에는 개별 항목을 삭제할 수 있는 **'삭제' 버튼**이 포함됨.
- **삭제 확인 절차**:
    - '삭제' 버튼 클릭 시, 실수 방지를 위해 `AlertDialog`를 통해 "정말 삭제하시겠습니까?"라는 확인 과정을 거침.
- **합계 계산**:
    - 목록에서 항목이 추가되거나 삭제될 때마다 실시간으로 전체 요금의 합계를 재계산하여 화면에 표시함.
- **금액 표기**:
    - 모든 금액 출력 시 천 단위 구분 기호(쉼표, `,`)를 포함함 (예: `15,500원`).

## 5. UI/UX 설계

### 5.1 레이아웃 구조
창은 세로 방향으로 크게 두 부분으로 나뉩니다.

1. **상단 영역 (Input Section)**:
    - 입차 날짜/시각 입력 컨트롤 (`DatePicker` & `TimePicker`)
    - 출차 날짜/시각 입력 컨트롤 (`DatePicker` & `TimePicker`)
    - [계산하기] 버튼

2. **하단 영역 (Display Section)**:
    - **목록 영역**: 스크롤 가능한 데이터 테이블 또는 리스트 형태.
    - **합계 영역**: 현재 목록에 있는 모든 요금의 총합을 강조하여 표시.

### 5.2 인터랙션 및 초기 상태
- **초기 상태**: 프로그램 실행 시 빈 입력 필드, 빈 목록, 그리고 합계 '0원'이 표시된 상태로 시작함.
- **계산 클릭**: 입력된 정보를 바탕으로 계산을 수행하고, 성공 시 목록의 가장 위에 새로운 항목을 추가함.
- **삭제 클릭**: 확인창에서 승인 시 해당 행을 리스트에서 제거하고 합계 금액을 즉시 갱신함.
- **오류 발생**: 입력 값이 부적절할 경우 즉각적인 피드백(`SnackBar`) 제공.
