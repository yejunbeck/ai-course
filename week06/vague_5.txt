전화번호를 어떤 형식으로 정리하고 싶으신가요? 상황에 따라 필요한 함수가 다를 수 있습니다. 가장 많이 쓰이는 세 가지 패턴(숫자만 추출, 하이픈(-) 삽입, 특정 형식으로 통일)을 기준으로 파이썬 코드를 작성해 드립니다.

### 1. 숫자만 남기고 모두 제거하기 (Clean up)
입력된 데이터에 공백, 하이픈, 괄호 등이 섞여 있을 때 숫자만 깔끔하게 뽑아내는 함수입니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 제거
    return re.sub(r'[^0-9]', '', str(phone))

# 테스트
print(clean_phone_number("010-1234-5678"))    # 01012345678
print(clean_phone_number("(02) 123-4567"))    # 021234567
print(clean_phone_number("010.1234.5678"))    # 01012345678
```

---

### 2. 표준 하이픈(-) 형식으로 만들기 (Formatting)
숫자만 있는 데이터를 `010-1234-5678` 또는 `02-123-4567` 형태로 변환합니다. 한국 전화번호 체계(휴대폰, 지역번호)를 고려한 로직입니다.

```python
def format_phone_number(phone):
    # 1. 일단 숫자만 추출
    digits = re.sub(r'[^0-9]', '', str(phone))
    length = len(digits)

    # 2. 길이에 따라 포맷팅
    if length == 11:  # 010-1234-5678 형태
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10:
        # 02-1234-5678 (서울 지역번호 2자리) 또는 010-123-4567 (일부 구형)
        if digits.startswith('02'):
            return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
        else:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9:  # 02-123-4567 형태
        return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
    else:
        return digits  # 형식이 맞지 않으면 그대로 반환

# 테스트
print(format_phone_number("01012345678"))    # 010-1234-5678
print(format_phone_number("021234567"))      # 02-1234-567
print(format_phone_number("010-123-4567"))   # 010-123-4567
```

### 3. [종합판] 데이터 정제용 함수 (추천)
실무에서는 **"지저분한 데이터를 넣으면 -> 숫자만 뽑아서 -> 예쁜 하이픈 형식으로"** 바꿔주는 기능이 가장 유용합니다.

```python
import re

def standardize_phone(phone):
    """
    지저분한 전화번호를 입력받아 
    표준 하이픈 형식(010-0000-0000)으로 정리합니다.
    """
    if not phone:
        return ""
    
    # 숫자만 추출
    digits = re.sub(r'[^0-9]', '', str(phone))
    n = len(digits)
    
    # 한국 전화번호 패턴 대응
    try:
        if n == 11: # 010-1234-5678
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif n == 10:
            if digits.startswith('02'): # 02-1234-5678
                return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}"
            else: # 010-123-4567
                return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        elif n == 9: # 02-123-4567
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else:
            return digits # 너무 짧거나 긴 경우 그대로 반환
    except Exception:
        return digits

# 실전 테스트
raw_data = [
    "010-1234-5678",
    "02.123.4567",
    "(010) 1234 5678",
    "01012345678",
    "021234567",
    "abc-010-1234-5678-xyz"
]

cleaned_data = [standardize_phone(p) for p in raw_data]
print(cleaned_data)
# 출력: ['010-1234-5678', '02-123-4567', '010-1234-5678', '010-1234-5678', '02-123-4567', '010-1234-5678']
```
