전화번호를 어떤 형식으로 정리하고 싶으신가요? 상황에 따라 가장 많이 쓰이는 세 가지 패턴(하이픈 추가, 숫자만 추출, 특정 포맷 통일)을 기준으로 Python 함수를 만들어 보았습니다.

### 1. 숫자만 남기고 하이픈(`-`)을 넣어 예쁘게 만들기
사용자가 `01012345678`, `010-1234-5678`, `010 1234 5678` 등 제각각으로 입력해도 모두 `010-1234-5678` 형식으로 통일합니다.

```python
import re

def format_phone_number(phone_str):
    # 1. 숫자 이외의 모든 문자 제거
    digits = re.sub(r'\D', '', str(phone_str))
    
    # 2. 길이에 따른 포맷팅 (휴대폰 번호 기준)
    length = len(digits)
    
    if length == 11: # 010-1234-5678
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    elif length == 10: # 02-123-4567 또는 010-123-4567
        if digits.startswith('02'): # 서울 지역번호인 경우
            return f"{digits[:2]}-{digits[2:5]}-{digits[5:]}"
        else: # 일반적인 10자리
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
    elif length == 9: # 02-12-3456 등 짧은 번호
        return f"{digits[:2]}-{digits[2:4]}-{digits[4:]}"
    else:
        # 형식이 맞지 않으면 숫자만 반환하거나 에러 처리
        return digits

# 테스트
test_numbers = ["01012345678", "010-1234-5678", "010 1234 5678", "021234567", "0101234567"]
for num in test_numbers:
    print(f"{num}  =>  {format_phone_number(num)}")
```

### 2. 데이터 분석용: 숫자만 추출하기 (Clean Data)
DB에 저장하거나 계산을 위해 특수문자를 모두 제거하고 숫자만 남기고 싶을 때 사용합니다.

```python
def clean_phone_number(phone_str):
    # 숫자(\d)가 아닌 것(\D)을 찾아 빈 문자열('')로 대체
    return re.sub(r'\D', '', str(phone_str))

# 테스트
print(clean_phone_number("010-1234-5678")) # 출력: 01012345678
print(clean_phone_number("(02) 123-4567")) # 출력: 021234567
```

### 3. 리스트 전체를 한꺼번에 정리하기 (Pandas 활용)
엑셀 파일이나 CSV 데이터를 다루신다면 `Pandas` 라이브러리를 사용하는 것이 가장 효율적입니다.

```python
import pandas as pd
import re

def clean_phone_series(series):
    # 숫자가 아닌 것을 제거하는 함수 정의
    def formatter(x):
        digits = re.sub(r'\D', '', str(x))
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    return series.apply(formatter)

# 예시 데이터프레임 생성
df = pd.DataFrame({
    'name': ['Kim', 'Lee', 'Park', 'Choi'],
    'phone': ['010-1234-5678', '01012345678', '(02)1234567', '010 1234 5678']
})

# 함수 적용
df['phone_cleaned'] = clean_phone_series(df['phone'])

print(df)
```

### 요약: 어떤 것을 선택할까요?
1. **화면에 보여주는 용도:** 1번 함수 (`format_phone_number`)
2. **DB 저장/데이터 전처리 용도:** 2번 함수 (`clean_phone_number`)
3. **엑셀/대량의 데이터 정리 용도:** 3번 방식 (`Pandas`)
